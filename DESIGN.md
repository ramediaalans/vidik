# DESIGN.md — ВИДИК

## 1. Бренд

**Название:** ВИДИК (VIDIK)
**Тэглайн:** «Твоё детство на перемотке»
**Суть:** интерактивная цифровая среда, в которой постсоветское детство 90-х и начала 2000-х можно не читать, а включать.

Тон: тёплый, разговорный, с лёгкой иронией, без пафоса и без музейной серьёзности. Русский язык — единственный язык интерфейса. Английский допустим только в оригинальных названиях фильмов, игр, групп и технологий.

## 2. Креативное направление

Главный принцип: **Серая реальность × яркое воображение.**

| Реальность | Воображение |
| --- | --- |
| пыльный ковёр, панелька, тюль | кислотная наклейка, обложка картриджа |
| выцветший беж и серо-зелёный | electric blue, acid, magenta |
| статичный интерьер | свет экрана, движение, шум |

Сайт не воссоздаёт 90-е буквально: это современный premium-продукт, который помнит 90-е. Никакого «музея СССР», никакой политики, никакого generic vaporwave.

## 3. Цветовая система (токены)

```
--ink        #0B0B0C   основной фон (CRT black)
--panel      #141416   поверхность
--panel-2    #1C1B1E   поднятая поверхность
--line       #2B2A2E   границы
--dust       #8A8580   вторичный текст (пыльный серый)
--bone       #EDE6D6   основной текст (тёплый белый)
--beige      #D8C9AC   выцветший беж
--blue-cold  #6C8CA8   выцветший синий
--blue       #2F6BFF   electric blue (основной акцент)
--purple     #7A4BD0   VHS purple
--magenta    #FF3E88   сигнальный акцент
--acid       #C9F03A   кислотный акцент
--amber      #FFB23F   тёплый акцент (лампа)
--burgundy   #7A1F2B   ковёр / глубокий тёплый
```

Правило: на экране одновременно не более двух ярких акцентов. Яркость приходит из изображений, а не из плашек.

## 4. Типографика

- **Дисплей:** Unbounded (700/800) — заголовки разделов, hero.
- **Пиксель-акцент:** Pixelify Sans — числа каналов, годы, счётчики, «системные» подписи. Никогда не для длинного текста.
- **Текст:** Onest — абзацы, карточки, UI.
- **Моно:** JetBrains Mono — метаданные, источники, технические подписи.

Шкала: 12 / 14 / 16 / 18 / 22 / 28 / 40 / 64 / 96. Межстрочный: 1.15 для дисплея, 1.55 для текста. Заголовки — uppercase с letter-spacing −0.02em; пиксель-шрифт — uppercase, +0.06em.

## 5. Сетка и ритм

- Контейнер 1280px, поля 24px (desktop) / 16px (mobile).
- Сетка 12 колонок, gutter 24px.
- Вертикальный ритм секций: 96px desktop, 64px tablet, 48px mobile.
- Скругления: 2 (пиксельные элементы), 8 (кнопки, поля), 16 (карточки), 24 (крупные панели).

## 6. Компоненты

`Navigation`, `Hero`, `SectionHeader`, `MediaCard` (+ `MovieCard`, `GameCard`, `MusicCard`), `FilterBar`, `RetroTV`, `RetroComputer`, `NostalgiaGenerator`, `YearSelector`, `CassettePlayer`, `MediaViewer`, `MediaResolver`, `SourceCard`, `Modal`, `Marquee`, `Footer`, `CRTFrame`, `VHSFrame`.

Правила:
- Карточка = фотография объекта эпохи + типографика поверх. Текст названия всегда рисует UI, а не изображение.
- Кнопка: прямоугольная, 8px скругление, 1px граница, заливка только у главного действия.
- Любой новый блок собирается из существующих токенов и компонентов; новый визуальный язык не изобретается.

## 7. Работа с изображениями

- Все изображения — оригинальные, сгенерированные через Genspark MCP (см. `IMAGE_GENERATION.md`).
- Единая цветокоррекция: тёплая пыль + один холодный источник света (экран).
- Никаких процедурных подделок: CSS-градиент не заменяет фотографию, SVG не изображает постер.
- Обложки реальных фильмов/игр/альбомов не используются. Вместо них — оригинальные предметные фотографии носителя (кассета, картридж, экран), а название даёт интерфейс.
- Формат: WebP, ширина 1600/800, lazy-loading ниже первого экрана.

## 8. Эффекты

Разрешено дозированно: film grain (overlay, ≤6% opacity), scanlines только внутри CRT-рамок, лёгкая виньетка, halation на hover изображений.
Запрещено: глитч на всём экране, неон везде, пиксель-шрифт везде, CRT-фильтр поверх всего сайта.

## 9. Движение

- Длительности: 120ms (hover), 220ms (карточки, модалки), 420ms (переходы каналов).
- Кривая: cubic-bezier(.2,.7,.2,1).
- Смысловые анимации: переключение канала = вспышка шума, перемотка кассеты = движение катушек, загрузка = boot-строки.
- `prefers-reduced-motion` отключает шум, дрожание и автопрокрутку.

## 10. Доступность

Семантический HTML, видимый focus-ring (2px acid), контраст текста ≥ 4.5:1, alt у всех изображений, управление клавиатурой в ТВ, плеере и модалках, Esc закрывает MediaViewer, «Пропустить загрузку» у boot-экрана.

## 11. Адаптив

- Desktop ≥1200: 12 колонок, крупный hero, ТВ в две колонки.
- Tablet 768–1199: 8 колонок, ТВ вертикально, карточки 2 в ряд.
- Mobile <768: отдельная композиция — вертикальный hero, горизонтальные ленты с прокруткой, нижняя панель навигации, ТВ во весь экран. Это не сжатый десктоп.

## 12. Do / Don't

**Do:** одна атмосфера на всём сайте · фотография как источник цвета · короткие русские фразы · интерактив вместо витрины.
**Don't:** музей СССР · Windows 95 clone · Netflix clone · случайные GIF · машинный перевод · фейковые плееры · заглушки вместо изображений.
