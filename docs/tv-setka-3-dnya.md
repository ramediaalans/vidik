# Сетка вещания «ВИДИК» — 3 канала × 3 дня

> АРХИВ: исходное редакционное ТЗ, а не текущее состояние приложения. Приоритеты балансеров и объём поиска ниже исторические. Активный эфир использует VK/Rutube/YouTube и generated; данные — app/src/tv/airtime.json, алгоритм — schedule.ts. Текущая развёрнутая сетка — tv-grid-3-days.md; руководство — project-guide.md. Не восстанавливать старые интеграции по этому плану.

Версия для утверждения. После утверждения — поиск конкретных роликов на Rutube / VK Видео / балансерах.

## Правила сетки

- **Каркас часов статичен.** Одни и те же пояса каждый день — это и есть «программа передач». Меняется только наполнение.
- **Ротация A → B → C**, эпоха `2026-01-01` = день A, формула `(номер дня − эпоха) % 3`. Уже реализовано в `app/src/tv/schedule.ts`.
- **Время канонично, UTC+3.** Часовой пояс браузера не влияет.
- **Стык слотов добивается межпрограммкой**: реклама 90-х (Инвайт, Херши, МММ, Империал, Stimorol), заставки каналов, анонсы, короткие мультфильмы. Целевая точность стыка — до минуты.
- **03:00–06:00 на всех каналах** — настроечная таблица УЭИТ + 1000 Гц, рисуется своим кодом (`provider: generated`), контент не нужен.
- Эротики нет. Ночь = музыка нон-стоп, затем таблица.

## Приоритет источников

| Тип контента | Основной источник | Запасной |
|---|---|---|
| Советские передачи, телеигры, ВИD, Гостелерадиофонд | Rutube | VK Видео |
| Советские мультфильмы и детское кино | Rutube | VK Видео |
| Реклама 90-х, заставки, межпрограммка | Rutube | VK Видео |
| Зарубежные сериалы, аниме | балансер (Kodik / Vibix) | VK Видео |
| Полнометражные фильмы | балансер (Kodik / Vibix) | VK Видео |
| Клипы, музыка нон-стоп | Rutube | VK Видео |

При поиске: предпочтение записям, залитым **более года назад** — они уже пережили волну удалений. Официальные каналы (ВИDgital ViD, Гостелерадиофонд, Союзмультфильм, Мосфильм) — в первую очередь.

> Vibix на данный момент отдаёт заглушку «контент ещё не добавлен» на любой id, включая примеры из их собственной документации. Слоты, помеченные «балансер», собираем на Kodik; переключение на Vibix — правка одного файла, если поддержка починит.

## Объём работы по поиску

| Канал | Уникальных позиций на 3 дня | Основной источник |
|---|---|---|
| Первая кнопка | ~75 (в т.ч. ~25 мультфильмов и 12 серий теленовелл) | Rutube |
| Шестая кнопка | ~90 (сериальные серии) | балансер + Rutube |
| Видеосалон | 27 полнометров | балансер |
| Межпрограммка (общая) | ~40 роликов: реклама, заставки, анонсы | Rutube |

Итого ~230 единиц контента. Собираются в `app/src/tv/pool.json` с полями `provider`, `mediaId`, `durationSec`, `uploadedAt`, `title`.
